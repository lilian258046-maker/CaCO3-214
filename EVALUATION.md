What work well for agentic AI:

1.Logic: Given the app idea, the agent generated a structured step-by-step process, and strictly follow it.

2.Coding ability: The agent successfully generated core algorithms and python scripts for each step.

3.Diagnosis: The agent check results from each step and derive more specific probelem or diagnose issues

What did not work well for agentic AI:

1.No autonomous excution: The agent can't access local content such as VS Code so it can't run the code or fix the code independently. 

2.Wrong language used: Although the python language is required and emphasized in the beginning, the agent mistakenly use other languages and needs correction.
